# Dev style guide

Esta carpeta no es parte del sitio de ACA Ganadería — es una plantilla reutilizable extraída de este
proyecto para arrancar futuros frontends Next.js + Laravel con las mismas convenciones.

- [`CLAUDE.md`](./CLAUDE.md): la guía de convenciones en sí (estructura, patrones, naming, tooling).
- [`scaffold/`](./scaffold): configs base + archivos de ejemplo listos para copiar a un proyecto
  nuevo (ver la sección "Cómo arrancar un proyecto nuevo" al final de `CLAUDE.md`).

Se puede borrar esta carpeta del repo de ACA sin afectar el sitio — es autocontenida.
